Where to build 7 hubs so the most people get a 15-minute delivery.

Drone delivery only works if hubs sit close to demand. Every hub costs capital, so the question is which few locations reach the most people within a fixed response time.

  • Fixed capital budget
  • 15-minute service promise
  • Trade-off between coverage and travel distance

How I built it.

  1. 01

    Frame it

    I set up hub siting as a facility-location problem with a hard budget cap.

  2. 02

    Cover demand

    Maximal covering counts how many people a set of hubs reaches within 15 minutes.

  3. 03

    Keep it efficient

    p-median keeps the demand-weighted distance to the nearest hub low.

  4. 04

    Solve and test

    The model picked 7 hubs. I measured coverage against what the budget allowed.
